**HIGH TECH PS Host** هو مشروع استضافة متكامل لتفعيل ثغرات الجيلبريك والتعديل لأجهزة PlayStaton 4 و PlayStation 5 أوفلاين (بدون إنترنت) عبر متصفح الجهاز مباشرة باستخدام ثغرة **PsFree WebKit** ومحرك **GoldHen**.

---

## ✨ المميزات الرئيسيّة (Key Features)

- ⚡ **تفعيل بنقرة واحدة (One-Click Exploit):** تصميم عصري بختم تفاعلي لتشغيل الثغرة بسهولة.
- 📶 **دعم كامل بدون إنترنت (OffLine Ready):** تخزين كاش أوتوماتيكي عبر `Service Worker` و `HTML5 Cache`.
- 📦 **ملف واحد مجوف (Self-Contained File):** تم دمج شفرة ثغرة **PsFree** وقاعدة بياناتها مباشرة داخل `cache.js` دون الحاجة لملفات خارجية.
- 🎨 **واجهة مستخدم احترافية (Gamer HUD UI):** تصميم أنيق وجذاب يعتمد على ألوان النيون والتأثيرات الزجاجية (Glassmorphism).
- 💻 **دعم مختلف الإصدارات:** 
  - **PS4:** من الإصدار `5.00` حتى `11.02`
  - **PS5:** من الإصدار `9.00` حتى `13.60`
